Flux Guide & Documentation

Fast, zero-install, peer-to-peer sharing across any device.

⚡ How It Works

Flux connects nearby devices directly using WebRTC DataChannels with DTLS 1.2 encryption. Files fly directly device-to-device at native Wi-Fi speeds without cloud uploads or size limits.

🔗 Pairing Across Networks

Devices on the same local subnet (/24) discover each other automatically. For devices on different networks, mobile hotspots, or public tunnels, click Pair Device to connect using a 6-digit PIN or QR code.

🛡️ Cryptographic Integrity

Every byte is streamed and hashed with incremental SHA-256 on both sender and receiver. Transfers are only verified when both cryptographic digests match exactly.

Network Troubleshoot Guide

Follow these quick checks if nearby devices aren't appearing.

1
Connect to the same Wi-Fi

Both devices must be connected to the same Wi-Fi network or router for auto-discovery.

2
Check AP / Client Isolation

Some corporate or guest Wi-Fi networks block direct peer communication. If so, use Pair with Code to route through the secure relay.

3
Manual Pairing (Across Any Network)

Click "Pair Device" to display a 6-digit PIN and QR code. This works across guest networks and hotspots.

4
Browser Permissions

Make sure Flux is running on HTTPS (or localhost) so the browser enables WebRTC and File System Access.
